>
> Добавьте каталог zapret в исключения антивируса либо выключите обнаружение PUA (потенциально нежелательных приложений). Например, в Kaspersky есть параметр "Обнаруживать легальные приложения, которые злоумышленники часто используют для нанесения вреда". Если вы понимаете, как правильно настроить исключения, предпочтительно добавить исключение; при сомнениях безопаснее отключить обнаружение PUA.

## ⚙️Использование

1. Сначала включите безопасный DNS (Secure DNS)
    * В Chrome активируйте "Использовать безопасный DNS" и выберите провайдера, отличного от варианта "Поставщик по умолчанию"
    * В Firefox откройте "DNS через HTTPS", установите режим "Персональный", нажмите "Выбрать провайдера/поставщика" и укажите URL вручную. Например, `https://dns.google/dns-query` (Cloudflare может быть заблокирован)
    * Windows 11 позволяет включить Secure DNS непосредственно в настройках системы — [инструкция находится здесь](https://remontka.pro/dns-over-https-windows-11/). Для пользователей Windows 11 этот способ рекомендуется
    * На роутерах Keenetic включите параметр "Транзит запросов". Если его отключить, Secure DNS на компьютере может работать некорректно

2. Загрузите zip/rar-архив с [последнего релиза](https://github.com/Darkgluapplaud40/zapret-discord-youtube/releases/latest)

3. Откройте свойства скачанного архива и включите пункт "Разблокировать". При использовании 7-Zip или PeaZip это действие обычно не требуется

4. Извлеките архив в каталог, в пути к которому нет кириллицы и специальных символов

5. Запустите нужный скрипт
    * Для поиска подходящей стратегии: **`service.bat`** -> `Run Tests` -> `Standard tests` -> `All configs`
    * Для добавления в автозапуск: **`service.bat`** -> `Install Service` -> *выберите подходящую стратегию*

## ℹ️Кратко о файлах

- [**`general.bat ...`**](./general.bat) — ручной запуск стратегии

  Такой запуск удобен для проверки разных вариантов. Результат зависит от множества условий, поэтому **перебирайте стратегии (ALT, FAKE и другие), пока не найдёте работающий именно у вас вариант**

- [**`service.bat`**](./service.bat) — автозапуск и дополнительные операции:
  - <ins>**`Install Service`** — добавить выбранную стратегию в автозапуск (services.msc)</ins>
  - **`Remove Services`** — удалить стратегию и WinDivert из списка служб
  - **`Check Status`** — посмотреть состояние обхода и служб, включая стратегию автозапуска и WinDivert
  - **`Game Filter`** — изменить режим обхода для игр и других сервисов, использующих UDP и TCP на портах выше 1023.  
  **После изменения параметра стратегию необходимо перезапустить.**  
  Значение в скобках показывает текущее состояние: включено или выключено.
  - **`IPSet Filter`** — изменить режим обработки сервисов из `ipset-all.txt`.  
  Опция полезна для диагностики ресурсов, которые без zapret работают нормально  
  В скобках отображается активный режим:
    - `none` — IP-адреса не проходят проверку
    - `loaded` — проверяются адреса, входящие в список
    - `any` — под фильтр попадает любой IP-адрес  
  - **`Auto-Update Check`** — включить или выключить автоматическую проверку обновлений
  - **`Replace active fakes`** — заменить используемый фейк другим файлом из каталога `bin`
  - **`Update IPSet List`** — получить свежий `ipset-all.txt` из репозитория
  - **`Update Hosts File`** — обновить hosts <ins>**для восстановления веб-версии Telegram и подключения к голосовому чату Discord**</ins>
  - **`Check for Updates`** — вручную проверить наличие обновлений
  - **`Run Diagnostics`** — проверить распространённые причины неисправности zapret.  
  В конце процедуры можно очистить кэш <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=11 /> `Discord`; это иногда помогает при внезапном прекращении работы
  - **`Run Tests`** — открыть инструмент проверки стратегий:
    - `Standard tests` — проверка сайтов из `utils/targets.txt`
    - `DPI checkers` — проверка DPI у разных провайдеров, включая Cloudflare и Amazon


## ☑️Частые вопросы и неисправности

### После запуска `general*` нет видимого результата

- При запуске стратегии отдельным bat-файлом, а не через service, процесс обхода winws.exe должен появиться в панели задач.  
Если этого не произошло, обратитесь к [#522](https://github.com/Darkgluapplaud40/zapret-discord-youtube/issues/522)

### Не работает ни одна стратегия
- Откройте командную строку с правами администратора
- По очереди выполните следующие команды:

    `netsh winsock reset`
  
    `netsh int ip reset all`
  
    `netsh winhttp reset proxy`
  
    `ipconfig /flushdns`
  
- Перезагрузите компьютер

### Не открывается Telegram в браузере
Запустите **`service.bat`** и выберите **`Update hosts file`**. Если текущий hosts устарел, программа предложит обновить его вручную:  
  - Скопируйте всё содержимое из открывшегося блокнота
  - Откройте файл `hosts` в созданном каталоге через текстовый редактор, запущенный от имени администратора
  - Вставьте скопированный текст в конец `hosts` либо замените ранее добавленные аналогичные строки
  - Сохраните файл и проверьте подключение ещё раз. Если результата нет, убедитесь, что изменения действительно сохранились.

#### Результат не гарантирован. Если это не помогло, используйте [Desktop-версию](https://github.com/telegramdesktop/tdesktop/releases) с [локальным прокси](https://github.com/Darkgluapplaud40/tg-ws-proxy) или любым публичным прокси.

### Обход не запускается или перестал работать

> [!IMPORTANT]
> **Стратегии могут терять работоспособность со временем.**
> Вариант, который некоторое время работал, может перестать работать после его обнаружения.
> В проекте собрано много стратегий обхода. Если готовые варианты не помогают, создайте новую стратегию на основе одной из них, изменив её параметры.
> Описание параметров доступно [здесь](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

- Проверьте результаты `service.bat` -> `Run Diagnostics` и устраните найденные ошибки

- Убедитесь, что нужный адрес присутствует в списках доменов или IP-адресов

- Проверьте другие варианты (**`ALT`**/**`FAKE`** и остальные)

- Выполните полную переустановку по инструкции ниже

- См. [#765](https://github.com/Darkgluapplaud40/zapret-discord-youtube/issues/765)

### Как полностью переустановить или обновить проект?
- Сохраните добавленные вами ресурсы и данные
- Перезапустите устройство
- Откройте `service.bat` -> `Remove Services`
- Выполните `service.bat` -> `Run Diagnostics`; при наличии ошибок исправьте их, затем в конце выберите Y
- Удалите каталог zapret
- Загрузите свежую версию [со страницы релизов](https://github.com/Darkgluapplaud40/zapret-discord-youtube/releases) (`zapret-discord-youtube-...`)
- Нажмите ПКМ по архиву и откройте свойства. Если внизу справа доступен флажок разблокировки, установите его, нажмите применить и ОК
- Извлеките архив в новый каталог в корне диска, без пробелов и специальных символов
- Запускайте разные `general`-скрипты и проверяйте доступ к интернет-ресурсам. Если выбранный вариант не работает, закройте программу через значок замка в панели задач и попробуйте следующую стратегию
- После выбора рабочей стратегии добавьте её в автозапуск через `service.bat` -> `Install Service`

### Игра или приложение не работает при включённом zapret

- Проверьте, что в `service.bat` параметр `Game Filter` имеет значение **`disabled`**, а `IPSet Filter` — **`none`**. Иначе фильтрация может затронуть неожиданные ресурсы.

### Античит сообщает о WinDivert

- Ознакомьтесь с инструкцией: https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide

### Windows 7 требует цифровую подпись драйвера WinDivert

- В каталоге [`bin`](./bin) замените `WinDivert.dll` и `WinDivert64.sys` файлами с такими же именами из [zapret-win-bundle/win7](https://github.com/bol-van/zapret-win-bundle/tree/master/win7)

### После удаления через [**`service.bat`**](./service.bat) WinDivert всё ещё указан среди служб

1. Определите имя службы командой в командной строке Windows (Win+R, `cmd`):

```cmd
driverquery | find "Divert"
```

2. Остановите и удалите найденную службу:

```cmd
sc stop название_из_первого_шага

sc delete название_из_первого_шага
```

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/1384/1384060.png" height=18 /> YouTube

- Проверьте, включён ли [Secure DNS](#%EF%B8%8Fиспользование)
- Отключите блокировщик рекламы: известно, что YouTube начал активно противодействовать таким расширениям.
- Переберите остальные стратегии, особенно если раньше всё работало.
- См. также [#251](https://github.com/Darkgluapplaud40/zapret-discord-youtube/discussions/251)

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=18 /> Discord

- Убедитесь, что настроен [Secure DNS](#%EF%B8%8Fиспользование)
- Сначала желательно выяснить, какая стратегия открывает YouTube, и запустить её
- В `service.bat` выберите `Run Diagnostics` и очистите кэш Discord
- Проверьте, изменилось ли поведение приложения Discord после очистки кэша
- Откройте Discord в браузере: https://discord.com/app. Если веб-версия работает, можно временно пользоваться ей
- Если браузерная версия тоже недоступна, снова проверьте все стратегии: YouTube и Discord могут работать на разных вариантах
- См. также [#252](https://github.com/Darkgluapplaud40/zapret-discord-youtube/discussions/252)

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968804.png" height=18 /> Telegram

- Попробуйте [tg-ws-proxy](https://github.com/Darkgluapplaud40/tg-ws-proxy)
- Либо воспользуйтесь бесплатными MTProto-прокси, доступными в интернете

### Игры не работают

Игры используют разные схемы подключения, поэтому проверить и исправить каждую из них невозможно.

Наиболее общий порядок действий:
- в `service.bat` обновите ipset и активируйте `Game Filter`
- если этого недостаточно, дополнительно включите `ipset any`

Учтите: режим `ipset any` может нарушить открытие многих сайтов. Не оставляйте его включённым постоянно. Лучше определить все IP-адреса игры и добавить их в `ipset-all.txt`

Если проблема сохранится, создайте обсуждение в разделе [Discussions](https://github.com/Darkgluapplaud40/zapret-discord-youtube/discussions), а не issue, и дождитесь помощи других игроков.

### В списке нет подходящей проблемы

- Опишите её [здесь](https://github.com/Darkgluapplaud40/zapret-discord-youtube/issues)

## 🗒️Добавление адресов других ресурсов

Расширить перечень адресов для обхода можно через следующие файлы:
- **`list-general-user.txt`** — домены; поддомены учитываются автоматически
- **`list-exclude-user.txt`** — домены, которые нужно исключить, например когда IP сети есть в `ipset-all.txt`, но конкретный домен фильтровать не требуется
- **`ipset-all.txt`** — IP-адреса и подсети
- **`ipset-exclude-user.txt`** — IP-адреса и подсети, подлежащие исключению
  - Файлы **`*-user.txt`** создаются автоматически при первом запуске `zapret` или `service.bat`
